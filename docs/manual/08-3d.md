# 3D

*Build a complete 3D pipeline from a single image: reconstruct a textured 3D model, rig it with a skeleton, convert it between formats, animate it from your webcam, and even generate an explorable 3D world.*

AI Creative Center's 3D suite is a set of tabs that chain together naturally: generate a model in **Image → 3D model**, send it to **Rig 3D** to add a skeleton, animate it in **Animation / Mocap**, convert it for your target engine in the **Converter**, and build a surrounding scene in **3D World**. Each tab has a built-in interactive 3D viewer on the right (orbit, pan, zoom).

> **Edition:** The entire 3D suite requires **Full+**. This covers Image → 3D model (`cap.model3d` / `cap.threed`), Rig 3D (`cap.rig3d`), Mocap animation (`cap.mocap`), the Converter, and 3D World / WorldGen (`cap.world_gen`). Studio Pro adds nothing extra to these modules except model import.

Some tabs download large model weights on first use, and 3D World and rigging require a local Blender installation (auto-installed when needed). Each tab notes its requirements below.

## Image → 3D model (TRELLIS.2)

> **Edition:** Full+ · **Capability:** `cap.model3d` / `cap.threed`

**What it does** — Reconstructs a full 3D model — mesh plus PBR materials — from a single photo or generated image.
**Where to find it** — **3D Model** tab.

**Step by step**
1. Set the **Source image**: **Browse…**, **Use generated image** (the current image in the Images tab canvas), or **Use masked subject** (only the subject isolated by your canvas mask, background excluded).
2. Choose the **Quality / model** settings (resolution, export format, background removal).
3. Adjust the **Geometry** and **PBR texture** settings if you need more or less detail.
4. Set the **Seed** (or leave **Random** on).
5. Click **Generate 3D model**. On first use the weights (~25 GB) are downloaded; 24 GB VRAM is recommended.
6. When done, inspect the model in the viewer and use its buttons to **Open folder**, **Open in system viewer**, or **Save as…**.

**Parameters**

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Resolution** | Dropdown | 1024_cascade | 512 · 1024 · 1024_cascade · 1536_cascade | Reconstruction quality. 512 = fast; 1024_cascade = best; 1536_cascade = highest (more VRAM/time). |
| **Export format** | Dropdown | glb | glb · obj · ply · stl | File format of the exported model. |
| **Remove background (BiRefNet)** | Checkbox | On | On / Off | Isolates the subject before reconstruction. Recommended for generated images. |
| **Geometry detail** | Number | 49152 | 16384–262144 | Sparse-structure token budget. Higher = more detail, more VRAM and time. |
| **Image adherence** | Number | 6.5 | 0.0–20.0 | How closely the shape follows the image (typical 6.5). |
| **Sampling steps** | Number | 12 | 1–50 | Geometry sampling steps. |
| **Mesh faces (max)** | Number | 500000 | 1000–5000000 | Final mesh decimation (triangle count). |
| **Generate PBR texture** | Checkbox | On | On / Off | Generates and bakes PBR materials (color, roughness, metallic). Off = geometry only. |
| **Texture size** | Dropdown | 2048 | 1024 · 2048 · 4096 | Texture map resolution. Enabled only when textures are on. |
| **Texture adherence** | Number | 3.0 | 0.0–20.0 | How closely the texture follows the image. |
| **Texture steps** | Number | 12 | 1–50 | Texture sampling steps. |
| **Seed** | Number | 0 | 0 to 2³¹−1 | Fix it for reproducible results. Disabled while **Random** is on. |
| **Random** | Checkbox | On | On / Off | Uses a fresh random seed each run. |

**Advanced** *(collapsible)*

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Precision** | Dropdown | auto | auto · bf16 · fp16 · fp32 | Numeric precision of the model. |
| **Attention backend** | Dropdown | auto | auto · flash_attn · xformers · sdpa · sageattn | Attention implementation; leave on auto unless you know your GPU favors a specific one. |
| **Background color** | Dropdown | black | black · gray · white | Background used during reconstruction. |

**Tips for best results**
> - Use a clean, well-lit image of a single subject; keep **Remove background** on for generated art.
> - Start at **1024_cascade**; only step up to **1536_cascade** if you have the VRAM and need extra detail.
> - Lower **Mesh faces (max)** for lighter models destined for real-time engines.

## Rig 3D (SkinTokens)

> **Edition:** Full+ · **Capability:** `cap.rig3d`

**What it does** — Automatically predicts a skeleton and skinning weights for a character mesh and exports a rigged GLB/FBX, ready to animate.
**Where to find it** — **Rig 3D** tab.

**Step by step**
1. Set the **Source mesh**: **Browse…** or **Use last 3D model** (the last model made in the 3D Model tab).
2. Choose the **Skeleton / export** options.
3. Adjust **Skinning** if needed.
4. Click **Generate rig**. On first run ~4 GB of weights are downloaded, and Blender 4.0+ is required — the app offers to install it automatically via winget (~350 MB) if it isn't found.
5. Inspect the rigged model in the viewer.

**Parameters**

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Bone naming** | Dropdown | Keep model names | Keep model names · Mixamo · Unreal Engine 5 | Naming convention for the skeleton. Mixamo = Mixamo retarget; UE5 = UE5 Mannequin; Keep = original names. |
| **Export format** | Dropdown | glb | glb · fbx | glb = preview in viewer; fbx = for Mixamo / game engines. |
| **Origin at feet (bottom-center)** | Checkbox | Off | On / Off | Places the skeleton origin at the character's feet (recommended for Unreal/Unity). |
| **Transfer rig onto original mesh** | Checkbox | On | On / Off | Transfers the predicted rig onto the original high-detail mesh, preserving detail (recommended). |
| **Voxel postprocessing** | Checkbox | Off | On / Off | Refines skinning weights with a voxel pass (slower). |
| **Influences per vertex** | Number | 4 | 1–32 | Max bones influencing each vertex; higher = smoother deformation. |
| **Shade smooth angle** | Number (°) | 55.0 | 0.0–180.0 | Smoothing angle for shading. |

**Advanced (sampling)** *(collapsible)*

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Beam search** | Number | 10 | 1–20 | More beams + lower temperature = more deterministic skeleton. |
| **Temperature** | Number | 1.0 | 0.1–2.0 | Randomness of the skeleton prediction. |
| **Top-K** | Number | 5 | 1–200 | Sampling top-K. |
| **Top-P** | Number | 0.95 | 0.1–1.0 | Sampling top-P (nucleus). |
| **Repetition penalty** | Number | 2.0 | 0.5–3.0 | Discourages repeated tokens in the predicted rig. |

**Tips for best results**
> - Feed a character mesh, ideally in an A- or T-pose, for the cleanest skeleton.
> - Keep **Transfer** on to preserve the high-detail original geometry.
> - Choose the **Bone naming** that matches your target: Mixamo for Mixamo animations, UE5 for Unreal.

## Converter

> **Edition:** Full+ · **Capability:** 3D suite (`cap.model3d` / `cap.threed`)

**What it does** — Imports a 3D file in almost any format and re-exports it in the format you need. Runs headless via Blender.
**Where to find it** — **Converter** tab.

**Step by step**
1. Set the **Source 3D file** with **Browse…**.
2. Pick the target **Format**.
3. Adjust **Scale** and the texture/animation options.
4. Click **Convert**. Progress and messages appear in the log below. Output goes to `output/converted/`.

**Parameters**

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Format** | Dropdown | glTF Binary (.glb) | glb · gltf · fbx · usd · usdz · obj · dae · stl · ply · abc · bvh · x3d · dxf | Output format. GLB for web/Unity, FBX/USD/glTF for Unreal, DXF for AutoCAD (geometry only), STL for 3D printing. |
| **Scale** | Number | 1.0 | 0.001–1000.0 | Uniform scale factor applied on export. |
| **Embed textures in file** | Checkbox | On | On / Off | Packs textures into the output file where the format supports it. |
| **Include animations** | Checkbox | On | On / Off | Preserves animation tracks in formats that support them. |

> USD/USDZ/Alembic/DAE/DXF availability depends on the modules of your installed Blender build. Unreal projects: use FBX/USD/glTF (there is no `.uasset` export).

## Animation / Mocap

> **Edition:** Full+ · **Capability:** `cap.mocap`

**What it does** — Captures motion from your webcam (or imports a mocap file) and retargets it onto a rigged model's existing skeleton.
**Where to find it** — **Animation / Mocap** tab.

**Step by step**
1. Set the **Rigged model**: **Browse…** or **Use last rig**.
2. Choose a motion source:
   - **Webcam capture** — pick the **Webcam** index, click **Start capture**, move in front of the camera (a live preview updates), then **Stop capture**. The mocap environment (MediaPipe) is required and can be installed with the provided script.
   - **Import FreeMoCap session** — **Browse…** for a `.bvh` or `.fbx` you recorded/processed elsewhere.
3. Set the **Retarget / export** options.
4. Click **Apply animation**. The result appears in the viewer.

**Parameters**

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Webcam** | Number | 0 | 0–8 | Camera index for capture. |
| **Target skeleton** | Dropdown | auto | auto · Mixamo · Unreal Engine 5 | Bone-naming convention; must match the template chosen in the Rig tab. auto tries names as-is. |
| **Export format** | Dropdown | fbx | fbx · glb · bvh | Format of the animated output. |

> The animation is applied to the rig's existing skeleton (no new skeleton is created). If the model has no rig, the BVH armature is kept. Single-camera mocap gives indicative quality.

## 3D World (WorldGen)

> **Edition:** Full+ · **Capability:** `cap.world_gen`

**What it does** — Generates an explorable 3D scene from a photo (or from text): a mesh (GLB) and/or a photorealistic Gaussian splat, navigable with orbit and WASD controls.
**Where to find it** — **3D World** tab.

**Step by step**
1. Give the scene a **Name**.
2. Set an **Image** (starting photo) with **Browse…**, or leave it empty and write a **Prompt** to generate from text. (If the image is empty, the current Images-tab canvas image is used when available.)
3. Choose the **Output** mode, **Resolution**, and low-VRAM option.
4. If FLUX.1-dev weights are gated, paste your **HF token** (used only for the one-time download).
5. If this is your first run, click **Install module**, then **Generate scene**. Watch progress in the log; **Stop** cancels.
6. Explore the result in the **Viewer (orbit / 🚶 WASD)**, or open the standalone **Web player**.
7. Export the mesh with **Export FBX** or **Export OBJ**, or **Open folder** to reveal the files.

**Parameters**

| Control | Type | Default | Range / Options | What it does & when to change |
|---|---|---|---|---|
| **Name** | Text | `world` | free text | Project/output name. |
| **Image** | File path | empty | image file, or empty | Starting photo. Empty = generate from the prompt (or the canvas image). |
| **Prompt** | Text | empty | free text | Scene description / guidance. |
| **Output** | Dropdown | Mesh (GLB, exportable) | Mesh · Splat (photorealistic) · Both | What to generate. Mesh is exportable; Splat is photorealistic; Both produces mesh then splat. |
| **Resolution** | Number | 1600 | 512–4096 | Generation resolution. |
| **Low VRAM** | Checkbox | Off | On / Off | Reduces VRAM use for smaller GPUs. |
| **HF token** | Password | empty | token | Hugging Face token for the gated FLUX.1-dev weights (one-time download only). |

**Specializations** — In **Both** mode the mesh is generated first, then the splat automatically. A generated mesh (GLB) becomes available to the **Rig 3D** tab via *Use last 3D model*, so a scene can flow into the same rig → animate chain as a TRELLIS model.

**Tips for best results**
> - Use a photo with clear depth cues (a room, a landscape) for a convincing scene.
> - Choose **Splat** for photorealistic look-around, **Mesh** when you need to export to a game engine, **Both** to keep your options open.
> - Enable **Low VRAM** if generation runs out of memory; expect it to be slower.

## The 3D viewer

Every 3D tab embeds an interactive viewer on the right. Orbit, pan and zoom the model, and use the buttons to **Open folder**, **Open in system viewer**, or **Save as…**. If your GPU or driver cannot run the embedded WebGL viewer, the app falls back to a simple buttons-only viewer so generation still completes and you can open the file externally.
